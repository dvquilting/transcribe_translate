Transcribe & Translate
======================

Speech to text, translation and speech translation in one program. Everything
runs on your own computer - nothing is uploaded.

Start it from the Start menu, or right-click a file in File Explorer
("Transcribe & Translate" for audio and video, "Translate..." for text,
subtitle and Word files).

The window has four tabs:

  Transcribe          the speech in an audio or video file as text (.txt),
                      subtitles (.srt), a Word document or a PDF; optional AI
                      post-processing (smart paragraphs, a corrected copy, a
                      summary). "Translate..." takes the transcript straight
                      to the Translate tab.
  Translate           text you type or paste, or a .txt, .md, .srt or Word
                      file, translated with a local language model. The layout
                      is kept: paragraphs, subtitle timing, Word styles.
  Speech translation  an audio or video file to subtitles in another
                      language, and optionally a dubbed soundtrack in the
                      speaker's (or each speaker's) own voice.
  History             the jobs run so far and the files they saved: open a
                      file or its folder, or run the same input again.

Help (F1), Model files and Quit are at the top right, for every tab. One job
runs at a time, so each model has the graphics card to itself; the other tabs
can be set up meanwhile.

Speech translation
------------------
1. Choose the audio or video file.
2. Step 1: the speech model and the spoken language ("Detect automatically"
   works for most models; Cohere Transcribe needs it set). Tick "Several
   speakers" to find who speaks when; you can listen to and name each one.
3. Step 2: the translation model and the language to translate into.
4. Optional, Step 3: dubbed audio (see below).
5. Choose what to save, and press Translate.

  NAME.<language>.srt             translated subtitles (always)
  NAME.srt                        original subtitles
  NAME.<language>.bilingual.srt   original line above the translation
  NAME.<language>.txt             the translation as plain paragraphs
  NAME.<language>.dubbed.mp4      the dub (or .mkv / .mp3 / .m4a / .wav)

Only clone a voice with the speaker's permission (or your own voice). Cloned
audio gets a short notice that it was generated by AI and an inaudible
watermark. FFmpeg (an install option) is needed for video files and dubbing.

Models
------
Each model is downloaded the first time it is used (an internet connection is
needed once). They are shared with the separate Transcribe, Translate and
Speech Translate programs, so nothing is downloaded twice:
  speech models   0.4 - 4.3 GB each, in %USERPROFILE%\.cache\crispasr
  translation     1 - 22 GB each,    in %LOCALAPPDATA%\Translate\models
  voices          1.2 - 2.0 GB each (+ 38 MB to separate music), in
                  %USERPROFILE%\.cache\crispasr
"Model files" lists them and can delete them. They are kept when the program
is uninstalled; delete those folders to free the space.

Graphics cards
--------------
The program uses an NVIDIA GPU with CUDA (if the CUDA component was
installed), otherwise any GPU through Vulkan (NVIDIA, AMD, Intel), otherwise
the CPU. Models bigger than the graphics card are split between the card and
the CPU automatically (slower). Each tab shows which one is in use.

AI transcriptions and translations can contain mistakes. Check anything
important.

Command line
------------
tt_engine.exe, in the installation folder, does the same from a command
prompt:
  tt_engine transcribe INPUT ...
  tt_engine translate INPUT -t LANG ...
  tt_engine speakers / dub ...
("tt_engine COMMAND --help" lists the options).

Requirements
------------
Windows 10 or 11 (64-bit), a CPU with AVX2 (2013 or newer), 16 GB of RAM
(32 GB for the largest translation model).
