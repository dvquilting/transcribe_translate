Speech Translate
================

Three programs, all running on your own computer - nothing is uploaded:

  Speech Translate   turns the speech in an audio or video file into subtitles
                     in another language - and, if you like, into speech in
                     that language, in the speaker's own voice
  Transcribe         speech to text (.txt / .srt) in the original language
  Translate          translates text, Markdown, subtitle and Word files

Start them from the Start menu (folder "Speech Translate"), or right-click a
file in File Explorer.

Speech Translate
----------------
1. Choose the audio or video file.
2. Step 1: the speech model and the spoken language ("Detect automatically"
   works for most models; Cohere Transcribe needs it set).
3. Step 2: the translation model and the language to translate into.
4. Optional, Step 3: dubbed audio (see below).
5. Choose what to save, and press Translate.

It runs Transcribe and then Translate one after the other, so each has the
graphics card to itself. Files are saved next to the input (or in the folder
you choose):

  NAME.<language>.srt             translated subtitles (always)
  NAME.srt                        original subtitles
  NAME.<language>.bilingual.srt   original line above the translation
  NAME.<language>.txt             the translation as plain paragraphs

Subtitle timing comes from the speech step; sentences that run over several
subtitles are translated as a whole and divided again.

Dubbed audio (Step 3)
---------------------
Speaks the translation in the speaker's voice and fits each line to the
original timing (lines are sped up a little where needed). Music and sound
effects are separated from the voice and kept.

  Voice model   Qwen3-TTS (most natural; 10 languages), CosyVoice3 (no accent
                from the original language; 9 languages), OmniVoice (600+
                languages)
  Voice         "Clone the speaker's voice" or a built-in voice
  Save as       the video with the new soundtrack (and the subtitles), or
                MP3 / M4A / WAV

  NAME.<language>.dubbed.mp4      (or .mkv / .mp3 / .m4a / .wav)

By default the translation is spoken with the accent of a native speaker
(only the voice is cloned); tick "Keep the speaker's original accent" to copy
the accent too. OmniVoice keeps some of the original accent either way.

Only clone a voice with the speaker's permission (or your own voice): tick
"The speaker agreed..." for each file. Cloned audio gets a short notice that it
was generated by AI - spoken at the start, or for a video shown as the first
subtitle when there is no room before the first line - and an inaudible
watermark. Ffmpeg (an install option) is needed for dubbing.

Models
------
Each model is downloaded the first time it is used (an internet connection is
needed once):
  speech models   0.4 - 4.3 GB each, in %USERPROFILE%\.cache\crispasr
  translation     4 - 22 GB each,    in %LOCALAPPDATA%\Translate\models
  voices          1.2 - 2.0 GB each (+ 38 MB to separate music), in
                  %USERPROFILE%\.cache\crispasr
They are kept when the programs are uninstalled; delete those folders to free
the space.

Graphics cards
--------------
The programs use an NVIDIA GPU with CUDA (if the CUDA component was
installed), otherwise any GPU through Vulkan (NVIDIA, AMD, Intel), otherwise
the CPU. Models bigger than the graphics card are split between the card and
the CPU automatically (slower). The windows show which one is in use.

AI transcriptions and translations can contain mistakes. Check anything
important.

Command line
------------
transcribe_multi.exe and translate_text.exe, in the installation folder, do
the same from a command prompt ("--help" lists the options).

Requirements
------------
Windows 10 or 11 (64-bit), a CPU with AVX2 (2013 or newer), 16 GB of RAM
(32 GB for the largest translation model).
